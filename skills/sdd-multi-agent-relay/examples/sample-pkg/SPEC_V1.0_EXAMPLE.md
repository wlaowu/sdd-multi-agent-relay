## 1. 目标与显式非目标（Goals & Non-Goals）

### 1.1 本方案达成目标
- 支持按筛选条件创建订单异步 CSV 导出任务（含任务幂等防重与大结果集流式写盘）。

### 1.2 显式非目标（本批次明确不做）
- 本轮**不做** Excel（`.xlsx`）格式支持，**不重构**订单列表既有分页查询接口。

---

## 2. 核心业务规则与不变量（Invariants）

1. **`INV-01`（幂等锁）**：同一用户在 60 秒窗口内以相同筛选指纹触发导出，若原任务处于 `PENDING/RUNNING`，返回已有 `exportId`，产生 `0` 次重复后台作业。
2. **`INV-02`（数据一致性）**：导出启动时冻结查询截止时间戳 `snapshotAt`，后续新增订单不混入当次 CSV。

---

## 3. 数据模型、兼容性与接口契约

- `POST /api/orders/export`：请求 `{ filterHash, fromTs, toTs }`；进行中重复请求返回 `202 { exportId, deduplicated: true }`；无效时间窗返回 `400 EXPORT_INVALID_RANGE`（不透传内部 SQL 报错）。
